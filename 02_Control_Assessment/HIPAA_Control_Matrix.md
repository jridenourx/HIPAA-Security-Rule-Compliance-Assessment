# HIPAA Security Rule Control Assessment Matrix

**Organization:** Northstar Health Plan (Fictional)  
**Assessment Type:** Simulated Compliance Assessment  
**Framework:** HIPAA Security Rule  
**Reference Guidance:** NIST SP 800-66 Rev. 2

## Assessment Status Definitions

| Status | Definition |
|---|---|
| Effective | Available evidence supports that the control is implemented and operating. |
| Needs Improvement | Evidence indicates that the control exists but has identified weaknesses. |
| Not Demonstrated | Available evidence is insufficient to demonstrate implementation or operation. |
| Not Assessed | The control has not yet been evaluated. |

## Assessment Notes

- All controls are initially marked Not Assessed pending review of synthetic evidence.
- Evidence references will be linked to supporting documents in the Synthetic Evidence directory.
- Assessment conclusions will distinguish between control deficiencies and insufficient supporting documentation.
- Applicable implementation specifications will be evaluated individually, including their Required or Addressable designation.
- Addressable implementation specifications will be assessed for reasonableness and appropriateness within the fictional organization's environment.
