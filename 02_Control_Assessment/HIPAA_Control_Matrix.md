## 1. Assessment Status Definitions

| Status | Definition |
|---|---|
| Effective | Available evidence supports that the control is implemented and operating. |
| Needs Improvement | Evidence indicates that the control exists but has identified weaknesses. |
| Not Demonstrated | Available evidence is insufficient to demonstrate implementation or operation. |
| Not Assessed | The control has not yet been evaluated. |
| Not Applicable | The requirement or implementation specification does not apply to the assessed environment, with documented rationale. |

## 3. Implementation Specification Assessment Notes

### 3.1 Required Specifications

Required implementation specifications must be implemented when applicable.

The assessment will evaluate whether the organization has established appropriate safeguards and whether supporting evidence demonstrates implementation.

### 3.2 Addressable Specifications

Addressable implementation specifications must be evaluated individually.

For each specification, the assessment will determine whether:

1. The specification is reasonable and appropriate for Northstar's environment.
2. The specification has been implemented when reasonable and appropriate.
3. An equivalent alternative security measure has been implemented when the original specification is not reasonable and appropriate.
4. The organization's determination and supporting rationale are documented.

An Addressable designation does not mean the implementation specification can simply be ignored.

### 3.3 Not Applicable Specifications

The implementation specification for isolating health care clearinghouse functions under §164.308(a)(4)(ii)(A) is not applicable to Northstar's defined environment because the fictional organization does not operate a health care clearinghouse as part of a larger organization.

This determination is limited to the fictional organizational scenario and should be revisited if the organization's operating environment changes.

## 5. Assessment Notes

- All controls are initially marked Not Assessed pending formal review of synthetic evidence.
- Evidence references identify the primary supporting documents for each assessment area.
- Individual implementation specifications will be evaluated separately where applicable.
- Assessment conclusions will distinguish between control deficiencies, documentation gaps, and insufficient supporting evidence.
- A documented policy does not independently demonstrate that a control is implemented or operating effectively.
- Addressable implementation specifications will be evaluated based on the organization's fictional environment, risk analysis, and documented rationale.
- Any Not Applicable determinations will include supporting justification.
- Findings will be documented separately in the Compliance Gap Assessment and Corrective Action Register.
